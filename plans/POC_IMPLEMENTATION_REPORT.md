## 🏗️ Архитектура POC

### Поток обработки

```
1. GitHub Webhook → Cloudflare Worker
   ↓
2. Проверка подписи (GITHUB_WEBHOOK_SECRET)
   ↓
3. Парсинг события (issue_comment, pull_request_comment)
   ↓
4. Парсинг команды (/zai help)
   ↓
5. Проверка авторизации (GitHub Token)
   ↓
6. Обработка команды (handleHelpCommand)
   ↓
7. Публикация ответа в GitHub
   ↓
8. Логирование
```

### Ключевые компоненты

#### 1. **src/index.js** - Основной Worker
- Обработка HTTP запросов
- Проверка подписи webhook
- Маршрутизация событий
- Логирование производительности

#### 2. **src/lib/github.js** - GitHub API клиент
- Универсальный метод `request()` для API
- Проверка подписи webhook
- Публикация комментариев
- Проверка доступа пользователей

#### 3. **src/lib/commands.js** - Парсинг команд
- Поддержка `/zai <command>`
- Поддержка `@zai-bot <command>`
- Валидация команд
- Форматирование помощи

#### 4. **src/lib/handlers/help.js** - Обработчик команды
- Генерация сообщения помощи
- Публикация ответа
- Обработка ошибок

## 🚀 Как запустить POC

### Шаг 1: Перейти в папку POC
```bash
cd /workspace/AndreiDrang__zai-code-bot/poc
```

### Шаг 2: Установить зависимости
```bash
npm install
```

### Шаг 3: Авторизоваться в Cloudflare
```bash
wrangler login
```

### Шаг 4: Настроить секреты
```bash
# GitHub Personal Access Token (scope: repo, read:org)
wrangler secret put GITHUB_TOKEN

# Секрет для webhook (любая строка)
wrangler secret put GITHUB_WEBHOOK_SECRET
```

### Шаг 5: Деплой
```bash
npm run deploy
```

### Шаг 6: Настроить GitHub Webhook
1. Репозиторий → Settings → Webhooks
2. Add webhook
3. **Payload URL:** `https://zai-code-bot-poc.<account>.workers.dev`
4. **Content type:** `application/json`
5. **Secret:** тот же, что и `GITHUB_WEBHOOK_SECRET`
6. **Events:** `Issue comments`
7. **Active:** ✅

### Шаг 7: Тестировать
1. Создать issue в репозитории
2. Написать: `/zai help`
3. Бот должен ответить с сообщением помощи
